# novapatch.ie

Personal website of Nova Patch: writing, research, talks, and projects.

## Development

Use the Ruby version in `.ruby-version`, then install dependencies and preview the site locally:

```sh
bundle install
bundle exec jekyll serve
```

Build the production site with:

```sh
bundle exec jekyll build
```

GitHub Actions builds and deploys the site to GitHub Pages.

## Authorship and AI Assistance

This repository represents human knowledge management. I use generative AI for webmaster assistance, including editing support, formatting, site maintenance, metadata updates, and administrative text generation. Primary site content remains human-authored.
